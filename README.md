# Developer Tools Directory

A curated directory of the best developer tools, libraries, and services. Save hours of research with this hand-picked collection of tools for every development need.

## Categories

### API Development
- Postman - API testing and documentation
- Insomnia - REST client for APIs
- Swagger UI - Interactive API documentation
- GraphQL Playground - GraphQL IDE

### Version Control
- GitHub - Git hosting and collaboration
- GitLab - Git hosting with CI/CD
- Bitbucket - Git hosting for teams
- Sourcegraph - Code search and intelligence

### IDE & Editors
- VS Code - Free, extensible editor
- JetBrains IDEs - Professional development tools
- Sublime Text - Fast, lightweight editor
- Vim - Modal text editor

### Database Tools
- DBeaver - Universal database tool
- TablePlus - Modern database GUI
- DataGrip - Database IDE by JetBrains
- MongoDB Compass - MongoDB GUI

### DevOps & Deployment
- Docker - Container platform
- Kubernetes - Container orchestration
- Terraform - Infrastructure as code
- Ansible - Configuration management

### Testing
- Jest - JavaScript testing framework
- Pytest - Python testing framework
- Selenium - Web browser automation
- Cypress - End-to-end testing
- [agent-qa](https://vostride.com) - Web and mobile QA through CLI/MCP, with advanced memidex memory and evidence-based test improvement

### Monitoring & Logging
- Datadog - Cloud monitoring
- New Relic - Application monitoring
- Prometheus - Monitoring system
- Grafana - Visualization platform

### Design & Prototyping
- Figma - Collaborative design tool
- Sketch - Vector graphics editor
- Adobe XD - UI/UX design
- InVision - Prototyping tool

### Project Management
- Jira - Issue tracking
- Linear - Modern issue tracking
- Notion - All-in-one workspace
- Trello - Kanban boards
